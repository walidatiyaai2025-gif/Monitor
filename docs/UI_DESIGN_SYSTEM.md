# UI Design System

## Visual direction

Professional database mission control: dark technical surfaces, restrained cyan signal color, semantic green/yellow/red health states, high information density with strong spacing and hierarchy.

## Core states

- Healthy: green
- Warning: amber/yellow
- Critical: red
- Offline/Unknown: slate
- Development/demo: amber banner with explicit copy

## Components

Reusable shell, side navigation, topbar, glass panel, metric card, server row/card, health orb, severity chip, data banner, incident table, summary strip, settings card and snapshot-age labels.

## Accessibility and behavior

- Status is expressed by both color and text.
- Motion is subtle and non-essential.
- Responsive layout collapses from dense desktop command-center views to readable mobile stacks.
- No fake production state: preview values are always accompanied by DEVELOPMENT DATA messaging.
