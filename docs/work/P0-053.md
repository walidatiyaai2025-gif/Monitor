# P0-053 — Fresh-host IIS bootstrap and PowerShell 7 prerequisite hardening

**Issue:** #281  
**State:** IN PROGRESS  
**Boundary:** repository-only preparation; `#162 -> #116 -> #111` remains unchanged.

## Goal

Make the already-integrated SingleNode installer safe to start from a clean supported Windows Server, including a Windows PowerShell 5.1 operator shell, without weakening the existing fail-closed IIS preflight/deploy boundary.

## Required behavior

1. `Install-ProductionSingleNode.ps1` detects whether PowerShell 7 is installed and whether the current process is already running under PowerShell 7.
2. Missing PowerShell 7 is PlanOnly by default. Apply supports either:
   - **Online:** the pinned official `PowerShell/PowerShell` x64 MSI release URL; or
   - **Offline:** an operator-supplied MSI path.
3. The PowerShell MSI is SHA-256 pinned and must carry a valid Microsoft Corporation Authenticode signature.
4. After PowerShell 7 installation, the current Windows PowerShell process stops before any IIS/application mutation and instructs the operator to relaunch the same approved command under `pwsh`.
5. MSI reboot-required exit code `3010` fails closed before IIS mutation and requires reboot + rerun.
6. `Bootstrap-IisProductionSingleNode.ps1` robustly discovers .NET, ASP.NET Core 8 and ANCM, supports only approved Microsoft Hosting Bundle Online sources or an operator-supplied Offline installer, and retains optional Hosting Bundle SHA-256 validation plus Authenticode validation.
7. Hosting Bundle installation on a server where IIS already exists must not silently restart shared IIS services; an explicit `-AllowIisServiceRestart` during an approved maintenance window is required.
8. Windows feature/installer reboot-required state stops before application/IIS cutover.
9. Certificate PFX import is idempotent: an already-installed matching machine certificate is reused; binding/certificate drift remains fail-closed.
10. Existing authoritative order remains `bootstrap -> Test-IisProductionPrerequisites.ps1 -> Deploy-ProductionSingleNode.ps1`.

## Verified PowerShell 7 pin

The default Online prerequisite is the official PowerShell v7.4.16 x64 MSI:

- asset: `PowerShell-7.4.16-win-x64.msi`
- URL: `https://github.com/PowerShell/PowerShell/releases/download/v7.4.16/PowerShell-7.4.16-win-x64.msi`
- SHA-256: `2c0c2036b0032375ad4f7809a92d0b6fa4a8e4ee89a75211514c4cf55ae22495`

The digest was independently checked against the asset metadata returned by the official `PowerShell/PowerShell` GitHub release before this hardening was prepared.
