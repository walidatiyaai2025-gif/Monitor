# B800-019 — Functional acceptance boundary

## Decision

The repository does not currently contain or reference a supported browser automation harness. The web test project is an xUnit/.NET test project with no Playwright, Selenium or browser-driver package references, and repository search finds no Playwright, Selenium or Chromium harness.

B800 therefore does **not** introduce a new browser framework opportunistically inside this shared PR. That would add package/runtime/browser-install supply-chain scope, CI runner requirements and a new maintenance surface unrelated to the current evidence-wiring slices.

## Exact acceptance boundary for this PR

Functional acceptance is layered and non-browser:

1. **Controller/route metadata** — reflection/source regression tests validate route, authorization and antiforgery contracts.
2. **View/source contracts** — tests verify role-gated mutating controls, explicit unavailable states, cache-only GET wording and absence of SQL execution surfaces in Razor views.
3. **Pure projection tests** — B300/B400 projections are exercised directly with deterministic cached evidence and missing-evidence cases.
4. **Collector contract tests** — bounded SQL snapshot mapping, privacy/least-privilege boundaries and fail-closed optional evidence are regression-tested.
5. **Normal CI** — restore/build/test plus repository safety tooling must pass on the exact PR head.
6. **Real SQL acceptance where applicable** — collector changes are exercised against the repository's SQL Server acceptance workflow.
7. **Windows production-candidate workflow** — packaging/runtime hardening remains a separate exact-head gate where required.

## What this does not prove

This boundary does not claim pixel/layout correctness, JavaScript interaction fidelity, browser-specific accessibility behavior, real cookie/session navigation, or a real browser click-through of the full operator journey.

Those require a deliberately approved browser-harness task with pinned packages/browser runtime, CI installation strategy, artifact/log redaction rules and ownership for browser-version maintenance.

## Safety boundary

Documentation-only. No package references, workflow permissions, runtime code, production IIS/SQL state, RC.61 publication/selection, credentials or monitored-SQL permissions are changed.

## Evidence

- `tests/Monitor.Web.Tests/Monitor.Web.Tests.csproj` contains Microsoft.NET.Test.Sdk + xUnit only.
- Repository code search on the B800 branch returned no Playwright, Selenium or Chromium harness hits.
- Existing acceptance remains the layered controller/view/projection/collector + CI/Real-SQL/Windows evidence described above.
