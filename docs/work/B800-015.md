# B800-015 — Cross-page cached evidence consistency

**Umbrella:** #287  
**Branch:** `agent/b800-functional-screen-wiring`  
**PR:** #288  
**State:** IMPLEMENTED / EXACT-HEAD VALIDATION PENDING

## Objective

Confirm that the existing database, backup, SQL Agent and storage evidence is surfaced consistently between Server Details and the dedicated operator module pages without creating duplicate data contracts or synthetic health values.

## Result

The runtime surfaces already share the same cached evidence contracts:

- database aggregate/detail facts are visible on Server Details and Database Health;
- full-backup coverage is visible on Server Details and Backups;
- SQL Agent aggregate outcomes are visible on Server Details and Jobs, with bounded B400 run-history intelligence remaining an additional Jobs-only diagnostic layer;
- allocated storage facts are visible on Server Details and Storage, with bounded B400 logical-file I/O remaining an additional Storage-only diagnostic layer.

No extra UI duplication was introduced. Instead, regression coverage now locks the shared fields and explicit `Not collected` behavior.

## Regression evidence

Added `tests/Monitor.Web.Tests/B800CrossPageEvidenceConsistencyTests.cs` to verify the shared evidence field contracts across Server Details and dedicated module views.

## Safety boundary

Test/documentation-only recognition of existing wiring. No monitored-SQL collection, runtime mutation, permissions, credentials, production state or RC.61 state is changed.
