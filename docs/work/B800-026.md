## Objective

Lock the administrator-only SQL target onboarding workflow so a candidate connection is tested before durable registration mutation and secret inputs remain write-only.

## Regression contract

`tests/Monitor.Web.Tests/B800ConnectionLabWorkflowTests.cs` verifies:

- Connection Lab is protected by the named `MonitorPolicies.Manage` policy;
- Register/Test/credential replacement/cleanup/enable/disable endpoints remain POST + antiforgery protected;
- `tester.TestAsync` occurs before `registrations.Upsert` in the registration workflow;
- failed candidate testing invokes temporary owned-credential cleanup and returns validation/test feedback without durable registration mutation;
- successful registration proceeds to bounded snapshot refresh and redirects to Servers;
- SQL passwords are never repopulated into Razor value attributes and existing registration secret references are not rendered;
- visible Connection Lab controls map to the protected controller actions, including the dynamic Enable/Disable form.

## Safety boundary

No new connectivity capability, credential storage mode, monitored-SQL permission, production IIS/SQL state or RC.61 state is introduced. This task hardens regression coverage around the existing safe onboarding path.

Exact-head normal CI must pass before this slice is marked verified.
