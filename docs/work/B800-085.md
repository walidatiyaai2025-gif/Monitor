# B800-085 — Contextual export workflow completion

## Objective

Close the remaining UI-to-route discoverability gap for the already-merged B800-083 Server Intelligence and B800-084 Database Health contextual CSV exports. Reports & Diagnostics sends an operator to the bounded Servers workflow, but the selected Server Details page previously exposed no download control for either existing route.

## Implemented contract

- Server Details now detects a real registered export context only when `ServerCard.Id` parses to a non-empty GUID.
- Registered targets expose two Viewer+ GET download controls:
  - existing `EnterpriseReportsController.ServerIntelligence(...)`;
  - existing `EnterpriseReportsController.DatabaseHealth(...)`.
- Development/demo identities that are not GUID-backed are not offered an invalid contextual export link.
- Registered-but-unavailable targets still expose the downloads so the existing export contracts can communicate explicit `Unavailable` evidence rather than hiding the state.

## Safety / truth boundary

- No export schema, controller endpoint, collector, SQL query, refresh service, mutation or remediation path is added.
- Both downloads retain the existing controller-level `Monitor.Read` policy and resolve through `IMonitorReadService.GetServerAsync(...)`.
- Opening Server Details remains cache/control-plane only. Downloading either contextual CSV remains cache/control-plane only.
- Existing `monitor-export-v2`, formula-safety, size/cell bounds, secure download headers, redaction and explicit `Unavailable` semantics remain authoritative.
- This slice does not publish/supersede RC.61 and does not satisfy or mutate #162/#116/#111 production acceptance.

## Regression evidence

`B800ContextualExportWorkflowTests` locks:

- GUID/non-empty registration gating for the two contextual links;
- direct wiring to the existing `ServerIntelligence` and `DatabaseHealth` actions;
- Viewer+ `Monitor.Read` authorization inheritance;
- `IMonitorReadService.GetServerAsync(...)` ownership;
- absence of monitored-SQL query/collector or snapshot-refresh dependencies from the export controller;
- Reports & Diagnostics continuing to route contextual selection through the bounded Servers workflow.
