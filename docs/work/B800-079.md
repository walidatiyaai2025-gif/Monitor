# B800-079 — Full Bounded Fleet Routing Coverage

**Umbrella:** #287  
**State:** canonical reconciliation in progress; exact reconciled-head validation pending  
**Scope:** read-only Fleet routing decision support only.

## Objective

Make Fleet routing coverage truthful when the complete bounded incident population contains more than the existing top-20 detail limit.

Before B800-079, `FleetDecisionSupport` evaluated B300 routing only for the first `MaxItems` incidents used by the visible detail table. `InputIncidents` could therefore be larger than the displayed routing population without a complete route-distribution summary.

B800-079 keeps the detail table bounded to 20 rows, but evaluates the existing deterministic `Batch300AlertRouting.Decide(...)` contract for every valid incident admitted by the complete bounded Fleet decision population and exposes an aggregate summary across that full population.

## Runtime behavior

`FleetDecisionSupport.Build(...)` now:

1. filters invalid incident identity exactly as before;
2. preserves deterministic severity/time/id ordering;
3. builds B400 correlation clusters exactly as before;
4. evaluates B300 routing once for every valid bounded incident;
5. summarizes the full evaluated population into counts for:
   - Page;
   - Notify;
   - Queue;
   - None;
   - suppressed policy state;
   - observed maintenance state;
   - unassigned owner state;
6. retains only the first `MaxItems` routing decisions for row-level display.

The route distribution is exhaustive for the admitted bounded decision population:

`Page + Notify + Queue + None = EvaluatedIncidents`

Suppression and maintenance counts are observed policy flags and may overlap each other. They are not additional mutually exclusive route buckets.

## UI behavior

The existing **ROUTING · RECOMMENDATION ONLY** panel now shows a coverage strip before the detail table:

- Evaluated
- Page
- Notify
- Queue
- No route
- Suppressed
- Maintenance
- Unassigned

The text explicitly states that the summary covers all incidents admitted by the complete bounded Fleet decision population while the table remains a deterministic top-20 detail view.

No notification is sent and no route recommendation is executed.

## Truth boundary

B800-079 is rendered only through the existing Fleet decision-support path, which B800-073/B800-076 already withhold when active incident evidence is truncated or required operator-policy evidence is unreadable.

Therefore this slice does not create a second completeness rule. It consumes the already-complete bounded population supplied to `FleetDecisionSupport.Build(...)`.

The summary does not claim global/unbounded incident coverage beyond that admitted decision population.
