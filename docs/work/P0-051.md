# P0-051 — RC.61 durable-promotion operator preflight

Parent: #162 / #116 / #111

## Goal

Reduce manual RC.61 promotion input error without changing the explicit manual publication boundary. Provide one read-only preflight that validates the selected source run/artifact provenance and emits the exact approved promotion and separate independent-verification commands.

## Acceptance

- [x] Pin the exact selected RC.61 repository, version, source run, artifact, outer digest, product SHA-256, source head, tested merge and release tag.
- [x] Require the canonical repository and `main` default branch.
- [x] Require the selected production-candidate run to be completed/successful with exact head and repository identity.
- [x] Require the selected Actions artifact to have exact ID/name/run/head/repository/digest, positive size and `expired=false`.
- [x] Report whether the durable release already exists.
- [x] Emit the exact `promote-existing-candidate` command from `main` with explicit `acknowledge_promotion=true`.
- [x] Emit the exact separate `verify-durable-release` command from `main`.
- [x] Never dispatch a workflow, create/mutate a tag or release, rebuild/repackage RC.61, deploy IIS, execute SQL, mark an external gate PASS or close #162/#116/#111.
- [x] Add regression coverage for exact identity, commands and fail-closed drift checks.

## Boundary

This is operator error-reduction only. Publication remains an explicit manual action governed by #162. External trusted-HTTPS IIS acceptance remains governed by #116 and #111.
