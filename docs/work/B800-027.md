## Objective

Lock the Administrator-only operational backup/restore surface in Settings, including validation, explicit destructive confirmation, audit and safe feedback.

## Regression contract

`tests/Monitor.Web.Tests/B800SettingsBackupRestoreTests.cs` verifies:

- Settings and `OperationalBackupController` use the named `MonitorPolicies.Manage` boundary;
- Create/Validate/Restore remain POST + antiforgery protected;
- Settings renders the three protected actions and only offers restore when backup readiness permits it;
- restore requires exact `RESTORE` confirmation and audits confirmation rejection plus final restore outcome;
- backup/restore feedback returns through `TempData["BackupStatus"]`;
- the page states and preserves the exclusion of secret ciphertext, Data Protection keys, connection strings and credential values.

## Safety boundary

No backup payload format, restore implementation, credential handling, production IIS/SQL state or RC.61 state is changed. This task adds regression coverage around the existing guarded workflow.
